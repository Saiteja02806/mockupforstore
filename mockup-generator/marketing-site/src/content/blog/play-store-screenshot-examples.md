## How to use this list

Pick **5–8** ideas that map to your real product. Order them as a story: promise → action → proof → settings/trust. Skip anything you cannot show honestly in UI.

3. Home dashboard “today” view

9. Widgets or live tiles  
10. Wearable companion  
11. Tablet split view  
12. Large text / accessibility  
13. Biometric lock  
14. Privacy dashboard  
15. Data export  
16. Integrations grid  
17. Search that actually works  
18. Media playback UI

30. “What’s new” feature spotlight
