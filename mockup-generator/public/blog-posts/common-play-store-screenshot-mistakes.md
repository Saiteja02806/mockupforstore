## Mistake 1: Illegible thumbnails

Beautiful full-screen art that **fails at browse size** is a silent conversion killer. Fix by testing exports at small widths and shortening copy.

## Mistake 2: Misleading UI or metrics

Fabricated balances, fake reviews in imagery, or features not in the build violate trust and policy. Align screenshots with **actual** builds per region.

## Mistake 3: Inconsistent frames

Mixing five phone styles reads as unpolished. Pick **one** chassis family for the set unless variance is intentional (e.g., foldable story).

## Mistake 4: Wall-of-text slides

If users need to read a paragraph, the slide has failed. Use **one** headline idea; move detail to in-app UI or long description.

## Mistake 5: Ignoring tablet tracks

Stretching phone comps for tablet slots looks lazy when large screens matter to your category.

## Mistake 6: Weak order

Random feature dumps beat no order—but a **story arc** beats both. See [how to create Play Store screenshots](/blog/how-to-create-play-store-screenshots/).

## Fix-it checklist

- [ ] Thumbnail test passed  
- [ ] Copy honest and localized safely  
- [ ] Frame + background system consistent  
- [ ] Dimensions verified ([size guide](/blog/play-store-screenshot-size-guide/))
